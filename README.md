# Calorie Capture

Eat smarter. Move better. Stay consistent.

Premium mobile-first fitness companion: AI meal photos, workouts with XP, streaks, friends, and gym-machine guides.

**Live:** https://k14shitija.github.io/calorie-capture/

The site entry is `index.html` at the repo root. Open that URL — the app boots into Kshitija’s demo day.

## Run locally

```bash
python3 -m http.server 8080
```

http://localhost:8080/

## Tests

node tests/test_engine.js
